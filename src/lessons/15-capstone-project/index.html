Module 15 Exercises

Exercise: Blog Listing Section

Extend the portfolio by adding a blog listing section between Skills and Testimonials. Requirements:

  • Use CSS Grid for the blog post layout (3-column on desktop, 1-column on mobile)
  • Each blog card should be a container query container
  • Cards should switch from horizontal to vertical layout based on their container width
  • Include a featured post that spans two columns and uses a different layout
  • Add entrance animations using @starting-style
  • Use color-mix() for subtle category-based color coding

Challenge: Project Detail with View Transitions

Create a project detail view using CSS View Transitions that morphs a project card into a full-page layout. Requirements:

  • Each project card links to its own detail page
  • Use view-transition-name on the card header, title, and tags
  • The card header should smoothly expand into a full-width hero banner
  • The title should animate from card position to page heading position
  • Tags should morph from inline to a sidebar layout on the detail page
  • Include a back button that reverses the transition
  • Use @view-transition navigation rule for MPA transitions
  • Ensure graceful degradation with @supports checks
