Advanced Typography & Variable Fonts

Fonts are not decorations. They are the interface. Every word your users read passes through your typographic choices — weight, width, spacing, size, decoration, ligatures, numerals. This module takes you past font-size and font-weight into the territory where type becomes a living, responsive, precisely controlled system. Variable fonts, fluid scales, text balancing, drop caps, color fonts, and OpenType features — the full arsenal for production-grade typography.

1. Variable Fonts

Traditional web fonts ship one file per weight: Regular.woff2, Bold.woff2, SemiBold.woff2. Want six weights? That is six HTTP requests and six separate files. Variable fonts collapse all of that into a single file that contains an entire design space — every weight from hairline to ultra-black, every width from condensed to expanded, all packed into one binary. You interpolate between extremes with CSS, getting any value along the axis.

The performance gains are immediate: one file replaces many. But the real power is precision. You are no longer locked to the weights the designer exported. You can set font-weight: 473 and get exactly that. You can animate weight on hover. You can adjust optical size at every breakpoint. Variable fonts turn typography from a discrete set of presets into a continuous, controllable spectrum.

Registered Axes

The OpenType specification defines five registered axes that variable fonts can expose. These are standardized, four-letter lowercase tags:

CSS

/* The five registered axes */
.text {
  font-weight: 473;            /* wght axis: 100-900 typically */
  font-stretch: 87%;           /* wdth axis: percentage-based */
  font-style: italic;          /* ital axis: 0 (normal) or 1 (italic) */
  font-style: oblique 12deg;   /* slnt axis: angle of slant */
  font-optical-sizing: auto;   /* opsz axis: auto-adjusts to font-size */
}

/* Direct axis control via font-variation-settings */
.precise {
  font-variation-settings:
    "wght" 473,
    "wdth" 87,
    "ital" 1,
    "slnt" -12,
    "opsz" 48;
}
Best practice: Use high-level CSS properties (font-weight, font-stretch, font-style) for registered axes whenever possible. Reserve font-variation-settings for custom axes or when you need to set multiple axes at once. High-level properties cascade and inherit correctly; font-variation-settings replaces the entire value on override, which means you can accidentally reset one axis when changing another.

Declaring Variable Fonts with @font-face

When you load a variable font, your @font-face rule must declare the range of each axis. This tells the browser that a single file covers the entire spectrum:

CSS

@font-face {
  font-family: "Inter Variable";
  src: url("InterVariable.woff2") format("woff2-variations");
  font-weight: 100 900;       /* full weight range */
  font-stretch: 75% 125%;     /* full width range */
  font-style: normal;
  font-display: swap;
}

/* Use it */
body {
  font-family: "Inter Variable", system-ui, sans-serif;
}

h1 { font-weight: 800; }
h2 { font-weight: 650; }
p  { font-weight: 380; }
.caption { font-weight: 320; }

Custom Axes

Beyond the five registered axes, type designers can create custom axes — identified by uppercase four-letter tags. These unlock unique design dimensions specific to that font:

CSS

/* Custom axes (uppercase tags) */
.expressive {
  font-variation-settings:
    "wght" 600,           /* registered: weight */
    "GRAD" 88,            /* custom: grade (visual weight without size change) */
    "XTRA" 468,           /* custom: x-axis transparency */
    "YOPQ" 79,            /* custom: y-axis opacity */
    "CASL" 0.7,           /* custom: casualness */
    "CRSV" 1,             /* custom: cursive */
    "MONO" 0;             /* custom: monospace proportion */
}

Animating Variable Fonts

Because variable font axes are continuous numeric ranges, you can animate them with CSS transitions and keyframes. This is impossible with static fonts:

CSS

.heading {
  font-weight: 400;
  transition: font-weight 0.3s ease;
}

.heading:hover {
  font-weight: 700;
}

/* Keyframe animation across axes */
@keyframes breathe {
  0%, 100% {
    font-variation-settings: "wght" 300, "wdth" 80;
  }
  50% {
    font-variation-settings: "wght" 700, "wdth" 120;
  }
}

.animated-text {
  animation: breathe 3s ease-in-out infinite;
}

2. Text Wrapping: balance & pretty

For decades, web typography had one ugly secret: line breaks were dumb. The browser filled each line to the max, then dumped whatever was left onto the next line. This produced ragged last lines, orphaned words dangling alone, and headings where one line had twenty words and the next had two. Print designers solved this manually. CSS now solves it automatically.

text-wrap: balance

text-wrap: balance redistributes text across lines so that each line has roughly equal length. It is designed for short blocks — headings, pull quotes, captions — not full paragraphs. The browser tries to minimize the difference between the longest and shortest lines:

CSS

/* Balance headings for even line lengths */
h1, h2, h3 {
  text-wrap: balance;
}

/* Also great for: */
blockquote {
  text-wrap: balance;
}

figcaption {
  text-wrap: balance;
}

/* Performance note: browsers limit balance
   to ~6 lines. Beyond that, it falls back
   to normal wrapping. Use it for headings,
   not body text. */

text-wrap: pretty

text-wrap: pretty is for paragraphs. It does not try to equalize line lengths. Instead, it looks ahead to prevent typographic crimes: orphans (a single word on the last line of a paragraph) and widows (the last line of a paragraph that lands alone at the top of a column). It also avoids awkward hyphenation breaks:

CSS

/* Prevent orphans in body text */
p {
  text-wrap: pretty;
}

/* Combine with hyphenation for maximum control */
.article-body {
  text-wrap: pretty;
  hyphens: auto;
  hyphenate-limit-chars: 6 3 3;
  hyphenate-limit-lines: 2;
  hyphenate-limit-zone: 8%;
}

/* white-space-collapse controls whitespace handling */
.code-output {
  white-space-collapse: preserve;  /* keep all whitespace */
}

.normalized {
  white-space-collapse: collapse;  /* default: collapse runs */
}

When to use which: Use balance for anything short — headings, pull quotes, figure captions, card titles. Use pretty for anything long — paragraphs, article text, descriptions. Never use balance on body text; it is computationally expensive for long blocks and browsers will ignore it past roughly six lines anyway. Both properties are progressive enhancements — browsers that do not support them simply fall back to normal wrapping.

3. Drop Caps with initial-letter

Drop caps are one of the oldest typographic traditions. The first letter of a chapter, enlarged and dropped into the paragraph, draws the eye and signals "start here." For years, web developers faked this with floats, manual font sizes, and fragile line-height hacks. The initial-letter property does it in one line, and it handles the alignment mathematics automatically.

CSS

/* Basic drop cap: spans 3 lines */
.article p:first-of-type::first-letter {
  initial-letter: 3;
  /* The letter occupies 3 lines of text.
     The browser calculates the font-size,
     line-height, and vertical alignment
     automatically. */
}

/* Raised cap: size 4, sink 2 */
.fancy p::first-letter {
  initial-letter: 4 2;
  /* First value: how tall (4 lines).
     Second value: how many lines it sinks into (2).
     The remaining 2 lines sit above the paragraph. */
}

/* Styling the dropped letter */
.styled p::first-letter {
  initial-letter: 3;
  color: #6c5ce7;
  font-weight: 800;
  font-family: Georgia, serif;
  margin-inline-end: 0.5rem;
  padding-inline: 0.15rem;
  background: rgba(108, 92, 231, 0.1);
  border-radius: 4px;
}

4. Font Palettes & Color Fonts

Color fonts are fonts that contain color information embedded directly in the glyphs. Instead of solid black outlines that you fill with color, each glyph can have multiple colored layers, gradients, or even bitmap textures. Think of emoji fonts — those are color fonts. But the technology extends far beyond emoji into decorative typefaces, brand fonts, icon sets, and artistic lettering.

The modern standard is COLRv1 (Color OpenType version 1), which supports gradients, compositing, and transformations. It is vector-based, resolution-independent, and compact.

Using Color Fonts

CSS

/* Color fonts work out of the box */
.emoji-heading {
  font-family: "Noto Color Emoji", sans-serif;
  font-size: 3rem;
}

/* The font-palette property selects a built-in palette */
.heading {
  font-family: "Bungee Spice", cursive;
  font-palette: --brand-colors;  /* custom palette */
}

/* Or use numbered palettes the font provides */
.alt-colors {
  font-palette: light;   /* predefined light palette */
}
.dark-alt {
  font-palette: dark;    /* predefined dark palette */
}

@font-palette-values

You can define your own color palettes that override specific colors within a color font. This is the @font-palette-values at-rule:

CSS

/* Define a custom palette */
@font-palette-values --brand-palette {
  font-family: "Bungee Spice";
  base-palette: 0;           /* start from the font's first palette */
  override-colors:
    0 #6c5ce7,                /* replace color index 0 */
    1 #a29bfe,                /* replace color index 1 */
    2 #0f1117;                /* replace color index 2 */
}

.brand-heading {
  font-family: "Bungee Spice";
  font-palette: --brand-palette;
}

/* Dark mode palette */
@font-palette-values --dark-palette {
  font-family: "Bungee Spice";
  base-palette: 0;
  override-colors:
    0 #a29bfe,
    1 #6c5ce7,
    2 #e4e6ef;
}

@media (prefers-color-scheme: dark) {
  .brand-heading {
    font-palette: --dark-palette;
  }
}

5. Advanced Text Decoration

The old text-decoration: underline gave you a thin line jammed against the text baseline, clipping through descenders. Modern CSS gives you complete control: thickness, offset, skip behavior, style, and an entirely separate emphasis system. Text decoration is now a precision tool, not a blunt instrument.

Thickness, Offset & Skip

CSS

/* Full control over underlines */
.refined-link {
  text-decoration: underline;
  text-decoration-color: #6c5ce7;
  text-decoration-thickness: 2px;
  text-underline-offset: 4px;
  text-decoration-skip-ink: auto;  /* default: skips descenders */
}

/* Thick decorative underline */
.highlight {
  text-decoration: underline;
  text-decoration-color: rgba(108, 92, 231, 0.3);
  text-decoration-thickness: 0.4em;
  text-underline-offset: -0.1em;  /* negative pulls it up into text */
}

/* Remove descender skipping for clean lines */
.no-skip {
  text-decoration-skip-ink: none;
}

Decoration Styles

CSS

/* Available decoration styles */
.solid     { text-decoration-style: solid; }
.double    { text-decoration-style: double; }
.dotted    { text-decoration-style: dotted; }
.dashed    { text-decoration-style: dashed; }
.wavy      { text-decoration-style: wavy; }

/* Combine line types */
.double-strike {
  text-decoration-line: underline overline;
  text-decoration-style: double;
  text-decoration-color: #ef4444;
  text-decoration-thickness: 1px;
}

/* Shorthand */
.full-shorthand {
  text-decoration: underline wavy #6c5ce7 2px;
}

text-emphasis

text-emphasis places marks above (or below) each character. This is different from underlines — it is used in East Asian typography to indicate stress or importance, but it works beautifully as a decorative tool in any language:

CSS

/* Emphasis dots above text */
.emphasis-dot {
  text-emphasis: dot;
  text-emphasis-color: #6c5ce7;
}

/* Other emphasis styles */
.emphasis-circle    { text-emphasis: circle; }
.emphasis-double    { text-emphasis: double-circle; }
.emphasis-triangle  { text-emphasis: triangle; }
.emphasis-sesame    { text-emphasis: sesame; }

/* Custom character as emphasis mark */
.emphasis-custom    { text-emphasis: "★"; }

/* Position: above or below */
.emphasis-below {
  text-emphasis: dot;
  text-emphasis-position: under;
}

6. OpenType Features: font-feature-settings & font-variant

Professional typefaces ship with dozens of hidden features baked into the font file: ligatures that merge character pairs, small caps designed at their own optical size, old-style numerals that blend into body text, tabular figures that align in tables, stylistic alternates that offer variant letter shapes, and swashes for decorative flourishes. Most of these features are off by default. CSS lets you activate them.

The High-Level Way: font-variant

CSS

/* Ligatures */
.ligatures-all {
  font-variant-ligatures: common-ligatures;           /* fi, fl, ff */
  font-variant-ligatures: discretionary-ligatures;    /* ct, st (decorative) */
  font-variant-ligatures: no-common-ligatures;        /* disable */
}

/* Small caps */
.small-caps {
  font-variant-caps: small-caps;        /* lowercase → small caps */
  font-variant-caps: all-small-caps;    /* everything small caps */
  font-variant-caps: petite-caps;       /* even smaller */
}

/* Numerals */
.oldstyle-nums {
  font-variant-numeric: oldstyle-nums;   /* 3 and 7 hang below baseline */
}
.tabular-nums {
  font-variant-numeric: tabular-nums;    /* equal-width digits for tables */
}
.lining-nums {
  font-variant-numeric: lining-nums;     /* uniform height digits */
}
.proportional-nums {
  font-variant-numeric: proportional-nums; /* natural-width digits */
}

/* Fractions */
.fractions {
  font-variant-numeric: diagonal-fractions;  /* 1/2 → proper fraction */
}

/* Stylistic alternates */
.alternates {
  font-variant-alternates: stylistic(alt-a);  /* alt glyph for "a" */
}

/* Combined */
.pro-typography {
  font-variant-ligatures: common-ligatures discretionary-ligatures;
  font-variant-caps: small-caps;
  font-variant-numeric: oldstyle-nums proportional-nums;
}

The Low-Level Way: font-feature-settings

The font-feature-settings property uses four-letter OpenType feature tags directly. It is more powerful (you can access any feature) but less maintainable (it overrides everything in one declaration):

CSS

/* Common feature tags */
.text {
  font-feature-settings:
    "liga" 1,   /* standard ligatures */
    "dlig" 1,   /* discretionary ligatures */
    "smcp" 1,   /* small caps */
    "onum" 1,   /* oldstyle numerals */
    "tnum" 1,   /* tabular numerals */
    "frac" 1,   /* fractions */
    "swsh" 1,   /* swashes */
    "salt" 1,   /* stylistic alternates */
    "ss01" 1,   /* stylistic set 1 */
    "ss02" 1,   /* stylistic set 2 */
    "kern" 1,   /* kerning (usually on by default) */
    "calt" 1;   /* contextual alternates */
}

/* Turn off a specific feature */
.code-block {
  font-feature-settings:
    "liga" 0,   /* disable ligatures in code */
    "calt" 0;   /* disable contextual alternates */
}
font-variant vs. font-feature-settings: Use font-variant-* properties as your default. They cascade properly, they are readable, and they do not clobber each other. Use font-feature-settings only when you need to access a feature that has no font-variant equivalent (like specific stylistic sets ss01-ss20) or when you need precise on/off control of multiple features at once.

7. Fluid Typography & Modular Scales

Module 6 introduced clamp() for responsive sizing. Now we go deeper. Fluid typography is not just "font-size that scales." It is a system: every typographic property — font size, line height, letter spacing, paragraph width — should respond to the viewport in a coordinated, proportional way. A modular type scale ensures that your heading sizes relate to each other mathematically, not arbitrarily.

The clamp() Pattern

CSS

/* clamp(minimum, preferred, maximum) */

/* Body text: 1rem at 320px, grows to 1.125rem at 1200px */
body {
  font-size: clamp(1rem, 0.95rem + 0.25vw, 1.125rem);
}

/* H1: 2rem at small, scales to 3.5rem at large */
h1 {
  font-size: clamp(2rem, 1.5rem + 2.5vw, 3.5rem);
}

/* H2: 1.5rem to 2.5rem */
h2 {
  font-size: clamp(1.5rem, 1.2rem + 1.5vw, 2.5rem);
}

/* The formula:
   preferred = min + (max - min) * (100vw - minVP) / (maxVP - minVP)
   Example for h1 (320px to 1200px):
   preferred = 2rem + (3.5 - 2) * (100vw - 320px) / (1200 - 320)
   simplified = 2rem + 1.5 * (100vw - 320px) / 880
              = ~1.45rem + 1.7vw
*/

Modular Type Scales

A modular scale uses a consistent ratio between sizes. Common ratios: 1.2 (minor third), 1.25 (major third), 1.333 (perfect fourth), 1.5 (perfect fifth). Pick a base size and multiply up:

CSS

/* Modular scale with custom properties */
:root {
  --scale-ratio: 1.25;  /* major third */
  --text-base: clamp(1rem, 0.95rem + 0.25vw, 1.125rem);

  /* Each step = previous * ratio */
  --text-sm:   calc(var(--text-base) / var(--scale-ratio));
  --text-md:   var(--text-base);
  --text-lg:   calc(var(--text-base) * var(--scale-ratio));
  --text-xl:   calc(var(--text-lg) * var(--scale-ratio));
  --text-2xl:  calc(var(--text-xl) * var(--scale-ratio));
  --text-3xl:  calc(var(--text-2xl) * var(--scale-ratio));
  --text-4xl:  calc(var(--text-3xl) * var(--scale-ratio));
}

h1 { font-size: var(--text-4xl); }
h2 { font-size: var(--text-3xl); }
h3 { font-size: var(--text-2xl); }
h4 { font-size: var(--text-xl); }
h5 { font-size: var(--text-lg); }
p  { font-size: var(--text-md); }
small { font-size: var(--text-sm); }

Fluid Line Height

Line height should decrease as font size increases. Large headings need tight leading; body text needs breathing room. Make it fluid:

CSS

/* Viewport-aware line height */
body {
  line-height: clamp(1.5, 1.4 + 0.5vw, 1.8);
}

h1 {
  line-height: clamp(1.05, 1.0 + 0.25vw, 1.2);
}

h2 {
  line-height: clamp(1.1, 1.05 + 0.25vw, 1.3);
}

/* Fluid letter-spacing: tighter at large sizes */
h1 {
  letter-spacing: clamp(-0.03em, -0.01em + -0.1vw, -0.02em);
}

/* Fluid measure (line length) */
.prose {
  max-inline-size: clamp(45ch, 50ch + 10vw, 75ch);
}
