Level 8 - Production Polish

Shapes, Clipping & Masking

Move beyond rectangles. Use clip-path to cut elements into circles, polygons, and organic SVG shapes. Wrap text around curves with shape-outside. Apply gradient and image masks with mask-image. Build animated reveals, diagonal sections, and production-ready visual effects with pure CSS.

1. clip-path Basics

The clip-path property cuts an element to a specific shape. Anything outside the clipping region is invisible -- it is not removed from the DOM, not hidden with opacity, and not collapsed with display: none. It simply does not render. The element still occupies its original rectangular box in the layout.

CSS provides four basic shape functions you can use directly in your stylesheet without touching SVG.

circle()

Clips the element to a circle. Takes a radius and an optional center position.

CSS

/* Circle at center, radius = 50% of element */
.avatar {
  clip-path: circle(50%);
}

/* Smaller circle, offset to the right */
.offset {
  clip-path: circle(40% at 60% 50%);
}

ellipse()

Like circle() but with independent horizontal and vertical radii.

CSS

/* Wide ellipse */
.banner {
  clip-path: ellipse(50% 35% at 50% 50%);
}

/* Tall, narrow ellipse at top-left */
.sidebar {
  clip-path: ellipse(30% 50% at 25% 40%);
}

inset()

Clips by insetting from each edge. Supports optional round for border-radius-style corners. This is how you create rounded rectangles as clip paths.

CSS

/* Inset 10px from all sides with rounded corners */
.card {
  clip-path: inset(10px round 16px);
}

/* Inset with different values per side */
.cropped {
  clip-path: inset(5% 10% 15% 10% round 8px);
}

polygon()

The most flexible basic shape. Define any number of x/y points, and the browser draws straight lines between them to create the clip region. This is where things get interesting.

CSS

/* Triangle */
.triangle {
  clip-path: polygon(50% 0%, 0% 100%, 100% 100%);
}

/* Hexagon */
.hexagon {
  clip-path: polygon(
    25% 0%, 75% 0%,
    100% 50%,
    75% 100%, 25% 100%,
    0% 50%
  );
}

/* Arrow pointing right */
.arrow {
  clip-path: polygon(
    0% 20%, 60% 20%,
    60% 0%, 100% 50%,
    60% 100%, 60% 80%,
    0% 80%
  );
}

2. clip-path: path()

Basic shapes cover geometric forms, but real design often needs organic, curved, or irregular outlines. The path() function accepts SVG path data -- the same d attribute syntax used in <path> elements. This gives you full control over curves, arcs, and complex contours.

SVG Path Syntax Crash Course

SVG path data uses single-letter commands followed by coordinates:

  • M x y -- Move to a point (starting position)
  • L x y -- Draw a straight line to a point
  • C x1 y1, x2 y2, x y -- Cubic Bezier curve (two control points + endpoint)
  • Q x1 y1, x y -- Quadratic Bezier curve (one control point + endpoint)
  • A rx ry rotation large-arc sweep x y -- Elliptical arc
  • Z -- Close the path (line back to start)

Lowercase versions (m, l, c, q, a) use relative coordinates. For clip-path, you typically work in pixels since path() does not accept percentages.

CSS

/* Organic blob shape */
.blob {
  clip-path: path(
    "M 150 0 C 250 0, 300 50, 300 150
     C 300 250, 250 300, 150 300
     C 50 300, 0 250, 0 150
     C 0 50, 80 0, 150 0 Z"
  );
}

/* Heart shape */
.heart {
  clip-path: path(
    "M 150 30
     C 105 -20, 0 20, 0 100
     C 0 180, 150 270, 150 270
     C 150 270, 300 180, 300 100
     C 300 20, 195 -20, 150 30 Z"
  );
}

/* Referencing an SVG clipPath element */
.complex {
  clip-path: url(#my-clip);
}

Using url() with SVG clipPath

For shapes that need to scale with percentage-based coordinates, embed an SVG <clipPath> element and reference it by ID. Set clipPathUnits="objectBoundingBox" so coordinates are relative to the element (0 to 1 instead of absolute pixels).

HTML + CSS

<svg width="0" height="0">
  <defs>
    <clipPath id="wave-clip" clipPathUnits="objectBoundingBox">
      <path d="M 0 0.3 Q 0.25 0, 0.5 0.3
               T 1 0.3 L 1 1 L 0 1 Z" />
    </clipPath>
  </defs>
</svg>

.hero {
  clip-path: url(#wave-clip);
}

3. clip-path Animations

Here is where clip-path gets powerful: you can transition and animate between shapes. The browser interpolates between clip-path values, creating smooth morphing effects. The one rule is that both the start and end states must use the same shape function and the same number of points (for polygon()).

Transitioning polygon()

When you transition between two polygon() values with the same number of vertices, each point smoothly moves from its start position to its end position.

CSS

/* Rectangle that morphs to a diamond on hover */
.morph {
  clip-path: polygon(
    0% 0%, 100% 0%,
    100% 100%, 0% 100%
  );
  transition: clip-path 0.5s ease;
}

.morph:hover {
  clip-path: polygon(
    50% 0%, 100% 50%,
    50% 100%, 0% 50%
  );
}

Circle Reveal

A circle clip-path that expands from nothing to full coverage creates a reveal effect.

CSS

.reveal {
  clip-path: circle(0% at 50% 50%);
  transition: clip-path 0.6s ease-out;
}

.reveal:hover {
  clip-path: circle(75% at 50% 50%);
}

Keyframe Animations

Use @keyframes for multi-step shape morphing that runs continuously.

CSS

@keyframes morph-shape {
  0%   { clip-path: polygon(50% 0%, 100% 50%, 50% 100%, 0% 50%); }
  25%  { clip-path: polygon(20% 0%, 80% 20%, 100% 80%, 0% 100%); }
  50%  { clip-path: polygon(0% 0%, 100% 0%, 100% 100%, 0% 100%); }
  75%  { clip-path: polygon(20% 20%, 80% 0%, 100% 100%, 0% 80%); }
  100% { clip-path: polygon(50% 0%, 100% 50%, 50% 100%, 0% 50%); }
}

.morphing {
  animation: morph-shape 4s ease-in-out infinite;
}

4. shape-outside

While clip-path changes how an element looks, shape-outside changes how other content flows around it. It applies to floated elements and defines a non-rectangular region that adjacent inline content wraps around.

This is the CSS property that makes magazine-style text wrapping possible. Text flows around circles, curves, and irregular shapes instead of being forced into rectangular columns.

Shape Functions

The same shape functions work here: circle(), ellipse(), polygon(), and inset().

CSS

/* Float an image and wrap text around a circle */
.profile-pic {
  float: left;
  width: 200px;
  height: 200px;
  shape-outside: circle(50%);
  clip-path: circle(50%);    /* match the visual */
  margin-right: 1.5rem;
}

/* Wrap text around a diagonal */
.diagonal-float {
  float: right;
  width: 300px;
  height: 400px;
  shape-outside: polygon(100% 0%, 100% 100%, 0% 100%);
}

shape-margin

Adds spacing between the shape boundary and the wrapping text. Without it, text hugs the shape edge too closely.

CSS

.float-circle {
  float: left;
  width: 180px;
  height: 180px;
  shape-outside: circle(50%);
  shape-margin: 1rem;   /* 1rem gap around the circle */
  clip-path: circle(50%);
}

Image-Based Shapes with url()

Use shape-outside: url(image.png) to derive the shape from an image's alpha channel. The browser traces the non-transparent pixels and wraps text around them. The image must be CORS-accessible.

CSS

.cutout-float {
  float: left;
  width: 250px;
  height: 300px;
  shape-outside: url("silhouette.png");
  shape-image-threshold: 0.5;  /* alpha threshold */
  shape-margin: 10px;
}

5. CSS mask-image

Masking is similar to clipping but more powerful. While clip-path creates hard edges (visible or not), mask-image supports partial transparency. Black areas of the mask are fully visible, transparent areas are hidden, and everything in between creates a gradient of opacity. This is how you build fade-out effects, image reveal patterns, and complex transparency composites.

Gradient Masks

The most common use case: fade an element's edges using a gradient as the mask.

CSS

/* Fade out at the bottom */
.fade-bottom {
  mask-image: linear-gradient(
    to bottom,
    black 60%,
    transparent 100%
  );
}

/* Fade both edges for a scrollable container */
.scroll-fade {
  mask-image: linear-gradient(
    to right,
    transparent,
    black 10%,
    black 90%,
    transparent
  );
}

/* Radial fade from center */
.spotlight {
  mask-image: radial-gradient(
    circle at 50% 50%,
    black 30%,
    transparent 70%
  );
}

SVG and Image Masks

Use an SVG or PNG image as the mask source. The alpha channel of the image determines what is visible.

CSS

/* SVG mask */
.masked {
  mask-image: url("mask-pattern.svg");
  mask-size: cover;
  mask-repeat: no-repeat;
}

/* Repeating pattern mask */
.dotted {
  mask-image: radial-gradient(
    circle 4px, black 100%, transparent 100%
  );
  mask-size: 12px 12px;
  mask-repeat: repeat;
}

mask-composite

When you layer multiple mask images, mask-composite controls how they combine. This creates effects like subtracting one shape from another.

CSS

.ring {
  mask-image:
    radial-gradient(circle, black 50%, transparent 50%),
    radial-gradient(circle, transparent 30%, black 30%);
  mask-composite: intersect;
  /* Produces a ring: only where both masks overlap */
}

/* Values: add, subtract, intersect, exclude */

Mask Sizing and Positioning

Just like background-image, masks have sizing, positioning, and repeat properties.

CSS

.custom-mask {
  mask-image: url("mask.svg");
  mask-size: 200px 200px;     /* or cover, contain, % */
  mask-position: center;
  mask-repeat: no-repeat;
  mask-mode: alpha;           /* or luminance */
}

6. Practical Patterns

Knowing the properties is one thing. Knowing when to reach for them is another. Here are the production patterns that come up most often.

Diagonal Section Dividers

Use clip-path: polygon() on full-width sections to create angled transitions between content areas. This replaces the old transform-skew hack.

CSS

/* Diagonal cut at the bottom */
.section-angled {
  clip-path: polygon(
    0 0, 100% 0,
    100% 85%, 0 100%
  );
  padding-bottom: 6rem; /* compensate for clipped area */
}

/* Chevron/arrow section divider */
.section-chevron {
  clip-path: polygon(
    0 0, 100% 0,
    100% 90%, 50% 100%,
    0 90%
  );
}

Profile Picture Cutouts

Clip user avatars to circles, hexagons, or rounded squares. Pair with a pseudo-element border for a clean outline effect.

CSS

.avatar-hex {
  width: 120px;
  height: 120px;
  clip-path: polygon(
    50% 0%, 100% 25%,
    100% 75%, 50% 100%,
    0% 75%, 0% 25%
  );
  object-fit: cover;
}

/* Border trick: slightly larger parent with same clip */
.avatar-border {
  padding: 4px;
  background: linear-gradient(135deg, #6c5ce7, #a29bfe);
  clip-path: polygon(
    50% 0%, 100% 25%,
    100% 75%, 50% 100%,
    0% 75%, 0% 25%
  );
}

Image Hover Reveal

Combine clip-path transitions with overlaid text for hover effects that reveal content beneath.

CSS

.card-reveal {
  position: relative;
  overflow: hidden;
}

.card-reveal .overlay {
  position: absolute;
  inset: 0;
  background: rgba(0, 0, 0, 0.7);
  clip-path: circle(0% at 50% 50%);
  transition: clip-path 0.5s ease;
  display: grid;
  place-items: center;
}

.card-reveal:hover .overlay {
  clip-path: circle(100% at 50% 50%);
}

Text Reveal Animation

Animate clip-path to reveal text line by line, or use mask-image with a moving gradient for a wipe effect.

CSS

/* Wipe reveal using animated mask position */
.text-wipe {
  mask-image: linear-gradient(
    to right,
    black 50%, transparent 50%
  );
  mask-size: 200% 100%;
  mask-position: right;
  transition: mask-position 0.8s ease;
}

.text-wipe:hover {
  mask-position: left;
}

7. Progressive Enhancement

Not every browser supports every clip-path or mask feature equally. @supports lets you detect feature support and provide fallbacks. The approach is simple: start with a working rectangular design, then enhance it when the browser supports shapes.

@supports for clip-path

CSS

/* Base: works everywhere */
.hero-image {
  border-radius: 12px;
  overflow: hidden;
}

/* Enhanced: only in browsers that support clip-path */
@supports (clip-path: polygon(0 0, 100% 0, 100% 100%)) {
  .hero-image {
    border-radius: 0;
    clip-path: polygon(
      0 0, 100% 0,
      100% 80%, 50% 100%,
      0 80%
    );
  }
}

@supports for mask-image

CSS

/* Base: visible overflow with opacity fade */
.scroll-container {
  overflow-x: auto;
}

/* Enhanced: gradient mask for scroll edges */
@supports (mask-image: linear-gradient(black, transparent)) {
  .scroll-container {
    mask-image: linear-gradient(
      to right,
      transparent, black 5%,
      black 95%, transparent
    );
  }
}

/* For WebKit browsers that need -webkit- prefix */
@supports (-webkit-mask-image: linear-gradient(black, transparent)) {
  .scroll-container {
    -webkit-mask-image: linear-gradient(
      to right,
      transparent, black 5%,
      black 95%, transparent
    );
  }
}

Vendor Prefix Considerations

As of 2026, clip-path is unprefixed in all major browsers. mask-image still requires -webkit-mask-image in some WebKit-based browsers. Always provide both prefixed and unprefixed versions for mask properties.

CSS

.fade-effect {
  -webkit-mask-image: linear-gradient(black 80%, transparent);
  mask-image: linear-gradient(black 80%, transparent);
}
Key Insight: The best progressive enhancement strategy is to make the rectangular version look intentional. If your design falls apart without clip-path, the design is fragile. If the rectangular fallback is simply a cleaner, simpler version, the enhancement is solid.

Exercise: Clip-Path Profile Cards

Build a row of profile cards that use clip-path and shape-outside. Each card has a hexagonal avatar, a diagonal header, and text that wraps around the avatar shape.

Requirements

  • Create 3 profile cards side by side using flexbox or grid.
  • Each card's header area should use clip-path: polygon() for a diagonal bottom edge.
  • The avatar inside each card should be clipped to a hexagon using clip-path: polygon().
  • In the card body, float the avatar and use shape-outside: circle(50%) so the bio text wraps around it.
  • Add a hover effect on the card that transitions the header's clip-path to a deeper diagonal.
  • Use @supports to fall back to border-radius: 50% for the avatar if clip-path is not supported.

Starter Code

HTML + CSS

<div class="profile-grid">
  <div class="profile-card">
    <div class="profile-header"></div>
    <div class="profile-body">
      <div class="profile-avatar"></div>
      <h3>Name</h3>
      <p>Bio text that wraps around the avatar...</p>
    </div>
  </div>
  <!-- repeat for 3 cards -->
</div>

.profile-header {
  clip-path: polygon(0 0, 100% 0, 100% 80%, 0 100%);
  transition: clip-path 0.3s ease;
}
.profile-card:hover .profile-header {
  clip-path: polygon(0 0, 100% 0, 100% 65%, 0 100%);
}
.profile-avatar {
  clip-path: polygon(50% 0%, 100% 25%, 100% 75%,
    50% 100%, 0% 75%, 0% 25%);
}

Challenge: Interactive Shape Gallery

Build a gallery of image cards that combines clip-path, mask-image, and animation. Each card should have a unique clip shape, a hover reveal effect, and a gradient mask that fades the bottom edge.

Requirements

  • Create a 2x2 grid of image cards.
  • Each card should have a distinct clip-path shape (circle, hexagon, diamond, rounded inset).
  • Add a hover effect that transitions each card from its unique shape to a full rectangle (reveal the entire image).
  • Apply mask-image with a bottom-fade gradient on the overall gallery container.
  • Add one card that uses a continuous @keyframes animation to morph between polygon states.
  • Include a text overlay on each card that appears on hover using clip-path: circle() reveal.
  • Apply @supports fallbacks for both clip-path and mask-image.
  • Respect prefers-reduced-motion by disabling animations when the user prefers reduced motion.
