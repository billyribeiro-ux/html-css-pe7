1. CSS if() Function

The CSS if() function brings inline conditional logic to CSS property values. Instead of writing multiple rules or media queries to switch between values, you can embed the condition directly in the value declaration. This is a paradigm shift for CSS: logic right where values live.

Syntax

CSS

/* Basic syntax */
property: if(condition: value-if-true; else: value-if-false);

/* Real example: component variant switching */
.card {
  --variant: default;

  width: if(style(--variant: compact): 200px; else: 400px);
  padding: if(style(--variant: compact): 0.75rem; else: 1.5rem);
  font-size: if(style(--variant: compact): 0.85rem; else: 1rem);
}

/* Compact variant */
.sidebar .card {
  --variant: compact;
}

Condition Types

The if() function supports several condition types, making it incredibly versatile:

style()

Tests the value of a custom property on the element.

/* Changes based on custom property value */
color: if(
  style(--theme: dark): white;
  else: black
);

/* Multiple conditions with chaining */
background: if(
  style(--status: success): #22c55e;
  style(--status: warning): #f59e0b;
  style(--status: error): #ef4444;
  else: #6b7280
);

media()

Tests a media query inline, without a full @media block.

/* Responsive values inline */
.container {
  padding: if(
    media(width >= 1024px): 3rem;
    media(width >= 640px): 2rem;
    else: 1rem
  );

  grid-template-columns: if(
    media(width >= 768px): repeat(3, 1fr);
    else: 1fr
  );
}

supports()

Tests for feature support inline.

/* Use modern features with fallback */
.layout {
  display: if(
    supports(display: grid): grid;
    else: flex
  );

  gap: if(
    supports(gap: 1rem): 1rem;
    else: 0
  );
}

Key Insight: The if() function does NOT replace @media, @container, or @supports at-rules. Those remain essential for controlling which rules apply. if() is for switching individual values within a single declaration. Think of it as a ternary operator for CSS values.

2. Sibling Functions

CSS finally has awareness of an element's position among its siblings. The sibling-index() and sibling-count() functions eliminate the need for nth-child hacks and JavaScript-set variables for positional styling.

sibling-index()

Returns the 0-based index of an element among its siblings. The first child has index 0, the second has index 1, and so on.

CSS

/* Staggered animation delays */
.card-list .card {
  animation: fade-in 0.5s ease backwards;
  animation-delay: calc(sibling-index() * 0.1s);
}

/* Progressive opacity */
.breadcrumb li {
  opacity: calc(0.4 + (sibling-index() * 0.15));
}

/* Dynamic hue rotation */
.color-swatch {
  background: oklch(0.7 0.15 calc(sibling-index() * 30));
}

sibling-count()

Returns the total number of siblings (including the element itself). This is incredibly powerful for dynamic layouts.

CSS

/* Auto-calculate grid columns based on item count */
.dynamic-grid > * {
  grid-column: span calc(12 / sibling-count());
}

/* Adjust font size when there are many items */
.tag-list .tag {
  font-size: if(
    style(sibling-count() > 10): 0.75rem;
    else: 0.9rem
  );
}

/* Equal-width flex items */
.nav-items > * {
  flex-basis: calc(100% / sibling-count());
}

3. Enhanced attr()

The attr() function has been dramatically upgraded. Previously, it could only return strings (for use in content property). Now it supports typed values: numbers, lengths, colors, and more. This means HTML data attributes can directly drive CSS values.

New Syntax

CSS

/* Old attr() - strings only, only in content */
.badge::after {
  content: attr(data-count);
}

/* NEW attr() - typed values in any property! */

/* Read a number */
.grid {
  grid-template-columns: repeat(attr(data-cols type(<number>), 3), 1fr);
}

/* Read a length */
.spacer {
  height: attr(data-height type(<length>), 1rem);
}

/* Read a color */
.tag {
  background-color: attr(data-color type(<color>), #6366f1);
}

/* Read a percentage */
.progress-bar {
  width: attr(data-progress type(<percentage>), 0%);
}

The Syntax Breakdown

                     to parse as       if missing

4. Customizable Select

Native <select> elements have been notoriously difficult to style. The new appearance: base-select value opts into a fully-customizable select that retains all native behavior (keyboard navigation, accessibility, form participation) while giving you complete CSS control.

Opting In

CSS

/* Opt into customizable select */
select,
::picker(select) {
  appearance: base-select;
}

/* Now you can style everything */
select {
  border: 2px solid #e2e8f0;
  border-radius: 10px;
  padding: 0.75rem 1rem;
  font-size: 1rem;
  background: white;
  cursor: pointer;
  min-width: 200px;
}

/* Style the dropdown picker */
select::picker(select) {
  border: 1px solid #e2e8f0;
  border-radius: 12px;
  padding: 0.5rem;
  box-shadow: 0 10px 40px rgba(0, 0, 0, 0.12);
  background: white;
}

/* Style individual options */
option {
  padding: 0.65rem 1rem;
  border-radius: 8px;
  transition: background 0.15s;
}

option:hover {
  background: #f1f5f9;
}

/* Style the selected option checkmark */
option::checkmark {
  color: #6366f1;
  font-weight: bold;
}

/* Style the dropdown arrow */
select::picker-icon {
  content: "\25BC";
  font-size: 0.7em;
  color: #64748b;
  transition: rotate 0.2s;
}

select:open::picker-icon {
  rotate: 180deg;
}

5. field-sizing

The field-sizing: content property makes form fields automatically grow or shrink to fit their content. No more JavaScript auto-resize hacks for textareas, and no more oversized input fields for short values.

CSS

/* Auto-growing textarea */
textarea {
  field-sizing: content;
  min-height: 3rem;     /* Minimum one line */
  max-height: 300px;    /* Cap the growth */
}

/* Input that fits its content */
input[type="text"] {
  field-sizing: content;
  min-width: 100px;
  max-width: 100%;
}

/* Even number inputs benefit */
input[type="number"] {
  field-sizing: content;
  min-width: 60px;
}

Values

  • field-sizing: fixed — Default behavior. Field uses its specified or default size.
  • field-sizing: content — Field grows and shrinks with its content. Respects min-width/max-width and min-height/max-height.

6. @function (Custom CSS Functions)

Custom CSS functions via @function let you define reusable value computations — similar to functions in programming languages. They accept parameters, perform calculations, and return CSS values. This is one of the most anticipated CSS features ever.

Syntax

CSS

/* Define a spacing scale function */
@function --spacing(--level) {
  result: calc(var(--level) * 0.25rem);
}

/* Use it throughout your stylesheet */
.card {
  padding: --spacing(4);        /* = 1rem */
  margin-bottom: --spacing(6);  /* = 1.5rem */
  gap: --spacing(3);            /* = 0.75rem */
}

.section {
  padding: --spacing(8) --spacing(4); /* = 2rem 1rem */
}

Advanced Examples

CSS

/* Fluid typography function */
@function --fluid-size(--min, --max) {
  result: clamp(
    var(--min),
    calc(var(--min) + (var(--max) - var(--min)) * ((100vw - 320px) / (1200 - 320))),
    var(--max)
  );
}

h1 { font-size: --fluid-size(1.75rem, 3.5rem); }
h2 { font-size: --fluid-size(1.5rem, 2.5rem); }
p  { font-size: --fluid-size(1rem, 1.125rem); }

/* Color palette generator */
@function --brand-color(--lightness) {
  result: oklch(var(--lightness) 0.18 265);
}

.primary   { color: --brand-color(0.55); }
.secondary { color: --brand-color(0.70); }
.muted     { color: --brand-color(0.85); }

/* Container-width percentage */
@function --col-width(--cols, --total) {
  result: calc((var(--cols) / var(--total)) * 100%);
}

.sidebar { width: --col-width(3, 12); }   /* 25% */
.main    { width: --col-width(9, 12); }   /* 75% */

7. Feature Detection

With so many cutting-edge features, progressive enhancement is essential. Use @supports to detect feature availability and provide fallbacks. Your CSS should always work without the newest features and enhance when they are available.

Detection Patterns

CSS

/* Detect CSS if() support */
@supports (width: if(style(--x: 1): 1px; else: 2px)) {
  .card {
    width: if(style(--variant: compact): 200px; else: 400px);
  }
}

/* Detect sibling functions */
@supports (animation-delay: calc(sibling-index() * 1s)) {
  .list-item {
    animation-delay: calc(sibling-index() * 0.1s);
  }
}

/* Detect enhanced attr() with type */
@supports (width: attr(data-w type(<length>), 0px)) {
  .data-driven {
    width: attr(data-w type(<length>), auto);
  }
}

/* Detect customizable select */
@supports (appearance: base-select) {
  select, ::picker(select) {
    appearance: base-select;
  }
  /* Custom select styles... */
}

/* Detect field-sizing */
@supports (field-sizing: content) {
  textarea {
    field-sizing: content;
    min-height: 2.5rem;
    max-height: 400px;
  }
}

/* Detect @function (via a resulting value) */
@supports (--custom: --spacing(1)) {
  .component {
    padding: --spacing(4);
  }
}

/* Combine multiple checks */
@supports (field-sizing: content) and (appearance: base-select) {
  .modern-form {
    /* Use both features together */
  }
}

/* Detect border-shape */
@supports (border-shape: circle()) {
  /* non-rectangular elements */
}

/* Detect gap decorations */
@supports (column-rule: 1px solid black) {
  /* gap decoration styles */
}

/* Detect @supports at-rule() — new in Chrome 148 */
@supports at-rule(@layer) {
  /* at-rule feature detection */
}

Progressive Enhancement Strategy

1

Baseline

Write CSS that works in all browsers. Use standard properties and values. This is your foundation that every user gets.

2

Detect

Wrap cutting-edge features in @supports blocks. Test for the exact property-value pair you intend to use.

3

Enhance

Inside the @supports block, apply the modern feature. Override or augment the baseline styles. The experience improves for capable browsers.

4

Test

Verify both paths: confirm the baseline works without the feature, and the enhancement works with it. Use browser DevTools to toggle feature flags.

8. CSS border-shape (Chrome 147, April 2026)

The border-shape property defines non-rectangular element geometry. Unlike clip-path, it redefines the element's actual geometry so borders, backgrounds, and hit-testing all follow the shape.

CSS

.badge {
  border-shape: polygon(0 50%, 50% 0, 100% 50%, 50% 100%);
  padding: 2rem;
  background: linear-gradient(135deg, #6366f1, #ec4899);
  color: white;
}

.blob {
  border-shape: shape(from 0% 50%, curve to 50% 0% with 0% 0%, curve to 100% 50% with 100% 0%, curve to 50% 100% with 100% 100%, curve to 0% 50% with 0% 100%);
}

/* Unlike clip-path, border-shape affects layout */
.diamond { border-shape: polygon(50% 0, 100% 50%, 50% 100%, 0 50%); }
How does this differ from clip-path?

clip-path only clips the element visually — the underlying box model remains rectangular. Borders still render as a rectangle, hit-testing uses the rectangular bounds, and text does not wrap to the clipped shape.

border-shape changes the element's actual geometry. Borders render along the defined shape, pointer events only fire within the shape boundary, and text content wraps inside the non-rectangular area. This is a fundamental change to how the element participates in layout.

9. CSS Gap Decorations (Chrome 149, May 2026)

Style gaps in grid and flex layouts with visible separators using column-rule-* and row-rule-* properties. These work similarly to column-rule in multi-column layouts but now apply to grid and flexbox gaps.

CSS

.grid-decorated {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 1.5rem;
  column-rule: 1px solid #e2e8f0;
  row-rule: 1px dashed #cbd5e1;
}

/* Full control */
.dashboard {
  display: grid;
  gap: 2rem;
  column-rule-width: 2px;
  column-rule-style: solid;
  column-rule-color: oklch(0.7 0.1 250);
  row-rule-width: 1px;
  row-rule-style: dashed;
  row-rule-color: oklch(0.8 0 0);
  column-rule-inset: 0.5rem;
  row-rule-inset: 0.25rem;
}
Why this matters:

This replaces the common hack of using borders on children to simulate gap lines. Previously, developers had to add border-right to grid items and use :last-child or :nth-child selectors to remove borders from edge items. Gap decorations handle this automatically, rendering lines only between items — never on the outer edges — and respecting the actual gap geometry regardless of item sizes.

10. CSS random() Function (Safari 26.2+, evolving syntax)

Generate random values in CSS without JavaScript. The random() function produces values within a specified range. Named random values produce consistent results across evaluations, and element-scoped randoms produce different values per element.

CSS

.confetti-dot {
  --hue: random(0, 360);
  --size: random(4px, 20px);
  --x: random(0%, 100%);
  background: oklch(0.7 0.15 var(--hue));
  width: var(--size);
  height: var(--size);
  left: var(--x);
}

/* Named random for consistent values across elements */
.card {
  --angle: random(--card-tilt, -5deg, 5deg);
  rotate: var(--angle);
}

/* Element-scoped: different value per element */
.particle {
  --drift: random(element-scoped, -50px, 50px);
  translate: var(--drift) 0;
}

11. shape() Function & offset-path (Chrome 137+)

The shape() function now works in offset-path for responsive animation paths, and in shape-outside for text wrapping. Unlike path() which uses fixed pixel coordinates, shape() accepts percentages and other relative units, making it responsive.

CSS

/* Responsive animation path */
.orbiter {
  offset-path: shape(from 0% 50%, curve to 50% 0% with 25% 0%, curve to 100% 50% with 75% 0%, curve to 50% 100% with 75% 100%, curve to 0% 50% with 25% 100%);
  offset-distance: 0%;
  animation: orbit 4s linear infinite;
}

@keyframes orbit {
  to { offset-distance: 100%; }
}

/* Float text around complex shapes */
.pull-quote {
  float: left;
  shape-outside: shape(from 0% 0%, line to 80% 0%, curve to 100% 50% with 100% 0%, curve to 80% 100% with 100% 100%, line to 0% 100%);
  width: 300px;
  height: 400px;
}

12. @custom-media (Firefox 148+)

Define reusable media query aliases for DRY, semantic breakpoints. Instead of repeating breakpoint values throughout your stylesheet, define them once and reference them by name.

CSS

@custom-media --mobile (max-width: 640px);
@custom-media --tablet (min-width: 641px) and (max-width: 1024px);
@custom-media --desktop (min-width: 1025px);
@custom-media --dark (prefers-color-scheme: dark);
@custom-media --motion-ok (prefers-reduced-motion: no-preference);

.hero {
  padding: 2rem;

  @media (--desktop) {
    padding: 6rem 4rem;
  }

  @media (--mobile) {
    padding: 1rem;
    font-size: 0.9rem;
  }
}
Why this matters:

This is the CSS equivalent of Sass variables for media queries. Instead of repeating breakpoint values everywhere, you define them once and reference them by name. When your breakpoints change, you update a single line rather than finding and replacing values scattered across your entire codebase.

13. revert-rule & Cascade Updates (Chrome 148, Firefox 150)

The revert-rule keyword rolls back a property value to the previous rule in the cascade, giving you fine-grained control over style resolution.

CSS

/* revert-rule rolls back to the previous rule in the cascade */
.special-btn {
  background: red;
  padding: 1rem 2rem;
}

@layer overrides {
  .special-btn {
    background: revert-rule; /* goes back to red from the previous rule */
    padding: revert-rule;    /* goes back to 1rem 2rem */
  }
}
How revert-rule differs from revert-layer:

revert-layer rolls back to the previous layer in the cascade — it undoes the entire layer's contribution. revert-rule is more granular: it rolls back to the previous rule within the same cascade context. This means you can selectively undo individual rules while keeping other rules from the same layer intact.

14. Media Pseudo-Classes (Firefox 150, April 2026)

New pseudo-classes for media elements let you style <video> and <audio> based on their playback state — no JavaScript event listeners needed.

CSS

video:playing { outline: 3px solid green; }
video:paused { opacity: 0.7; filter: grayscale(0.5); }
video:buffering { opacity: 0.5; }
audio:muted { opacity: 0.4; }
video:seeking::after {
  content: "Seeking...";
  position: absolute;
  top: 50%;
  left: 50%;
  transform: translate(-50%, -50%);
}

Exercise: Staggered Card List

Create a staggered card list where animation delays are automatically calculated using sibling-index(), and card columns adapt using attr().

Requirements

  • Create a grid container that reads its column count from a data-cols attribute using enhanced attr().
  • Add at least 8 cards to the grid, each with a fade-and-slide-up entrance animation.
  • Use sibling-index() to calculate each card's animation-delay as calc(sibling-index() * 0.1s).
  • Each card should show its index number (use a CSS counter or sibling-index() in content).
  • Cards that span multiple columns should use data-span with attr().
  • Include a @supports fallback: if sibling-index() is not supported, use :nth-child() with hardcoded delays.
  • Add hover effects that scale the card and increase box-shadow.

Starter Code

<div class="stagger-grid" data-cols="3">
  <article class="stagger-item">
    <h3>Card Title</h3>
    <p>Description text...</p>
  </article>
  <!-- Repeat for 8+ cards -->
</div>

<style>
.stagger-grid {
  display: grid;
  grid-template-columns: repeat(
    attr(data-cols type(<number>), 3), 1fr
  );
  gap: 1.5rem;

.stagger-item {
  animation: stagger-in 0.5s ease backwards;
  animation-delay: calc(sibling-index() * 0.1s);

}
</style>
