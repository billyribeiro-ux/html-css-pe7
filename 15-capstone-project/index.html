Practice

Exercise

Extend the portfolio with a blog listing section using CSS Grid and container queries. Each blog card should show a title, date, excerpt, and category tag. The cards should adapt their layout based on their container width — switching from a stacked layout in narrow containers to a side-by-side layout in wide ones.

Challenge

Add a project detail view with view transitions that morph the card into a full page. Use view-transition-name on the card elements (image, title, description) so they animate smoothly between the gallery view and the detail page. Create a separate HTML page for the detail view with a back button that transitions in reverse.
